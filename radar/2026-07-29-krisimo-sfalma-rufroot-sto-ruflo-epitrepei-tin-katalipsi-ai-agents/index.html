AI Security 29 Ιουλ 2026

Κρίσιμο σφάλμα «RufRoot» στο Ruflo επιτρέπει την κατάληψη AI agents Claude Code και Codex

Ερευνητές αποκάλυψαν σφάλμα μέγιστης σοβαρότητας (CVE-2026-59726, CVSS 10.0) στο Ruflo, ένα open-source meta-harness για AI agents που χρησιμοποιείται με το Claude Code της Anthropic και το Codex της OpenAI. Το σφάλμα επιτρέπει σε μη πιστοποιημένους επιτιθέμενους remote code execution και «δηλητηρίαση» της μόνιμης μνήμης του AI agent, ώστε η κακόβουλη συμπεριφορά να επιβιώνει ακόμη και μετά την επιδιόρθωση του λογισμικού.
