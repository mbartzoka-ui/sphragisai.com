AI Act10 Nov 2026

New York's RAISE Act takes effect, bringing new oversight to OpenAI and Anthropic

New York opened a registration portal on Tuesday for its RAISE Act, the state's AI safety and transparency law, which takes full effect on January 1, 2027. Large frontier AI developers with over $500 million in annual revenue, including OpenAI and Anthropic, will have to publish safety frameworks, report critical safety incidents within 72 hours, and issue public model transparency reports, with fines of up to $3 million per violation. Governor Kathy Hochul also launched a new oversight office called DIGIT and a research center at Binghamton University that will independently evaluate companies' safety frameworks. The same day, Australia announced its own mandatory AI incident reporting requirements following OpenAI's Medicare hack, showing that mandatory AI safety rules are no longer just a European trend. For a business relying on major AI providers, this growing patchwork of state and national rules is one more reason to ask providers for compliance documentation, not just technical support.

Australia announces mandatory AI incident reporting after OpenAI's Medicare hack

Australian Prime Minister Anthony Albanese said OpenAI will not face criminal penalties over last June's data breach at a Medicare statistics portal, but presented the findings of a rapid review and committed to changing criminal law so AI companies can no longer argue they didn't know what their systems were doing. For a Greek business, the move shows that mandatory AI incident reporting, already part of the EU AI Act, is becoming a common response by governments worldwide after real incidents, not just a theoretical safeguard.

AI Security11 Nov 2026

Microsoft shows how editing fewer than 10 neurons can backdoor an AI agent

Microsoft researchers unveiled a technique called Lazarus that plants a hidden backdoor in an AI model by editing fewer than 10 of its neurons, without any retraining. The targeted neurons rarely fire and barely affect the model's normal answers, but once a chosen trigger phrase appears, whether in a user's request or hidden inside a tool's output, the model executes an attacker's command with whatever permissions the AI agent itself holds. In tests on the Nemotron Terminal 8B model, editing just seven neurons made it run the hidden command in 98.8% of sessions containing the trigger, and never when the trigger was absent. Microsoft says it hasn't seen attackers use the technique yet and published defensive guidance alongside the research, but the findings show that an AI agent's security now also depends on who had access to the model's weights, not just the code running around it.

Google DeepMind's AI agents find cheaper ways to attack old RSA encryption keys

Google DeepMind announced that AI agents, working under human supervision, found two new ways to cut the computing cost of attacking obsolete 1024-bit RSA encryption keys, in a collaboration with cryptographers from UC San Diego and the French institute Inria. "Office Party" flaw in Claude allows code execution on Linux, Anthropic declines to fix it

Researchers at AIR Security found a flaw they named "Office Party" in Claude's official tools for creating and editing Word, PowerPoint and Excel documents, which lets an attacker run their own code on a Linux machine simply by placing a suitable file in a shared temporary folder before a user asks Claude to process a document. The issue lies in a helper script that launches LibreOffice to convert documents and loads a shared library without checking where it came from, so the malicious code runs with the same privileges as the user talking to Claude. Anthropic was told about the issue back in May and acknowledged it, but considers it outside its own "security boundary" because the code runs inside a sandbox, an isolated environment meant to stop code from affecting the rest of the system, something researcher Niv Hoffman calls inadequate, since the attacker's code still runs with the user's own permissions and access to the user's own files either way. For a business that trusts an AI vendor's official tools, the case shows that a vendor's claim that something "runs in a sandbox" doesn't necessarily cover the business's own risk boundary, and that every such add-on tool deserves to be treated like ordinary software that needs vetting.

Claude Code's "Don't Ask Again" file leaves passwords and keys exposed in 1,122 public GitHub repositories

Software security firm Apiiro found 1,122 public copies of a Claude Code settings file, Anthropic's coding assistant, containing at least one password or API key in plain, unencrypted text. When a developer selects "Yes, and don't ask again" for a command, Claude Code saves the exact command, including any secret it contains, inside the project's .claude/settings.local.json file, which it tries to keep out of git, though that protection only applies on the computer where it was set up and does nothing for older versions already recorded in git history or in forks of the repository. For a business that lets its developers use AI coding tools, the case shows that a simple convenience choice, "don't ask me again," can turn a password into a public secret forever, even if the file is deleted later.

Anthropic unveils FlashProve, a system to prove which AI model produced an answer

Anthropic announced FlashProve, an open-source system meant to let anyone verify that an AI response really came from the model its provider claims.
